Política de Privacidade - Encaixa

Última atualização: 13/11/2026.

Esta política explica quais dados o aplicativo Encaixa (pacote com.agsterr.encaixa2) usa.

1. Quem somos

Encaixa é um jogo de quebra-cabeça desenvolvido por Agsterr. Contato: focodevsistemas@gmail.com.

2. Dados coletados

  • Não há conta, cadastro nem login. Não pedimos nome, e-mail, telefone nem localização.
  • Dados do jogo (pontuação, recordes, gemas, progresso de fases e preferências de som) são guardados somente no seu aparelho, em armazenamento local. Não são enviados para nossos servidores.
  • Anúncios: o aplicativo mostra anúncios pelo Google AdMob. O AdMob pode usar um identificador de publicidade do aparelho e informações técnicas (modelo, versão do sistema, país) para exibir e medir anúncios, conforme a política de privacidade do Google.
  • Compras: compras no aplicativo (remover anúncios, gemas e assinatura) são processadas pelo Google Play. Não recebemos dados de pagamento.

3. Como usamos os dados

Os dados do jogo servem apenas para o funcionamento do jogo no seu aparelho. Os dados de anúncios servem para exibir e medir anúncios.

4. Compartilhamento

Não vendemos nem compartilhamos dados pessoais. Os dados de anúncios são tratados pelo Google, como descrito acima.

5. Crianças

O Encaixa não é direcionado a crianças. Não coletamos intencionalmente dados de menores de 13 anos.

6. Seus direitos e exclusão

Para apagar os dados do jogo, desinstale o aplicativo: os dados locais são removidos junto. Para apagar dados de anúncios, use as configurações de privacidade do seu aparelho (redefinir ou excluir o identificador de publicidade). Para outras dúvidas, escreva para focodevsistemas@gmail.com.

7. Alterações

Se esta política mudar, a nova versão será publicada nesta mesma página com a data atualizada.
